## 本次只做两件事

### 1. 最小数据记录

优先复用现有表，只增加管理后台真正需要的数据：

- 每日任务：日期、四步状态、时间和数量
- 来源结果：来源、发现/新增/重复数量、状态和错误
- 内容处理状态：当前步骤、状态、重试次数、错误、所用服务
- 补足感兴趣与未读/阅读中/已读表达

审查并收缩当前 `db/schema.ts` 和 `drizzle/0006_workflow_schema.sql`。不建设 Artifact、Prompt版本、复杂用量系统、依赖图或通用任务平台。同一天允许一个正式任务，也允许多次测试。

### 2. 固定四步后端

实现固定流程：

```text
采集 → AI整理 → 质量检查 → 发布
```

要求：

- 每一步更新状态并保存简明错误。
- 单个来源或内容失败不影响其他内容。
- 自动重试最多 5 次。
- 管理员可以重试失败来源或失败内容。
- 去重后再调用收费服务。
- AI重加工复用已保存的原始资料和文字稿。
- 测试运行不公开。
- 重复发布使用 upsert。

提供管理页面后续需要的最小接口：

- 查询今日任务和历史任务
- 立即运行
- 查询四步、来源和失败内容状态
- 重试失败来源或内容
