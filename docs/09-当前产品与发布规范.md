# InfoHub 当前产品与发布规范

本文件是代码仓库内的当前执行摘要；完整需求以项目根目录 `信息笔记系统PRDv1.md` v2.0 为准。

## 页面

| 页面 | 访问者 | 用途 |
|---|---|---|
| `index.html` | 所有人 | 日报、精选、收藏、我的 |
| `admin.html` | 管理员 | 精选文章列表、新增、草稿、预览、发布、隐藏与恢复 |

用户端不显示后台入口。公开网页由 GitHub Pages 托管；管理员写操作必须经过 Cloudflare Worker，浏览器不保存 GitHub Token。

## 内容

- 日报：X、热门论文、GitHub Trending，每日自动运行。
- 精选：编辑手工粘贴整理好的内容，不做链接抓取或 AI 加工。
- 私人数据：收藏、阅读进度、划线、笔记和主题只在浏览器本地保存。

## 精选字段

标题、卡片摘要、展示日期、类型、主题标签、Takeaways、正文、可选来源链接。主题由编辑者手动填写 1—2 个宽泛分类标签并随文章发布，不从关键词自动生成；正文使用纯文本：空行分段，简短独立行作为小标题。

## 当前依赖

- 日报：Moonshot/Kimi、GitHub Actions、GitHub Pages。
- 精选：Cloudflare Worker/KV、GitHub Contents API、GitHub Pages。
- 通知：Cloudflare Worker/KV、Web Push。

Get笔记、Supadata 和 YouTube transcript 不再参与正式流程。

## 备份

- Git 保存公开内容历史。
- `public/archive/daily/YYYY-MM.json` 保存日报月度副本。
- 用户通过“我的”导出/恢复私人 JSON。
- 连续使用超过一季度后再评估数据库或对象存储，不提前建设。
