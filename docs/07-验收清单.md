# InfoHub 验收清单（轻量版）

## A. 每日内容生产

- [ ] Follow Builders、技术动态 X、论文和 GitHub Trending 每天运行一次
- [ ] 单个来源失败不影响其他来源
- [ ] 重复内容不会重复加工或发布
- [ ] 采集、AI 整理、质量检查、发布四步状态清楚
- [ ] 失败最多自动尝试 5 次
- [ ] 质量检查通过后自动发布
- [ ] 失败原因可以在后台查看并重试

## B. 候选与文字稿

- [ ] YouTube频道发现阶段不获取文字稿
- [ ] 管理员可单条或批量处理候选
- [ ] 管理员可提交 YouTube、播客或文章链接
- [ ] Get笔记和 Supadata 可轮换与失败切换
- [ ] 已有文字稿重加工时不重复消耗额度
- [ ] 普通用户看不到提交入口和服务信息

## C. 内容可读性

- [ ] X 有中文内容和可点击的原始链接
- [ ] 论文有中文摘要、关键词、普通人价值和局限
- [ ] GitHub说明是什么、用途、关注原因、门槛和热度语境
- [ ] YouTube/播客先显示 Takeaways，再显示详细中文文章
- [ ] 每个板块有内容、趋势、价值、专业程度和数量总结
- [ ] 系统展示所有有效内容，不替用户做价值筛选

## D. 首页和详情

- [ ] 默认最新一期，显示最近 7 天和更多日期
- [ ] 不显示“今日采集/昨日采集”
- [ ] 首页按五个板块展示
- [ ] 用户可调整板块顺序或隐藏板块
- [ ] 打开详情始终从顶部开始
- [ ] 返回列表恢复原滚动位置
- [ ] 详情页提供感兴趣和上一篇/下一篇

## E. 私人阅读与笔记

- [ ] 感兴趣后进入未读
- [ ] 阅读后进入阅读中，主动完成后进入已读
- [ ] 感兴趣导航无数字角标
- [ ] 阅读进度跨网页和手机同步
- [ ] 只高亮用户实际选择的文字
- [ ] 批注、自由笔记、编辑和删除可用
- [ ] 私人数据按用户隔离
- [ ] 笔记可以导出 Markdown

## F. 管理后台

- [ ] 工作流页面展示今日四步和来源状态
- [ ] 可以立即运行和重试失败内容
- [ ] 候选内容页面可处理 YouTube 更新和管理员链接
- [ ] 内容管理可筛选、预览、编辑、重新加工、发布和撤下
- [ ] 设置可管理来源、频道、运行时间和 AI 加工规则
- [ ] 服务状态真实，且不显示完整 API Key
- [ ] 普通用户无法访问后台和管理员 API

## G. 手机、安全和工程质量

- [ ] 手机端首页、详情、感兴趣、笔记和后台重试可用
- [ ] 正文字号至少 17px，主要触控目标至少 44×44px
- [ ] API Key不进入前端、数据库明文、日志或 Git
- [ ] 现有真实内容和用户数据未被删除
- [ ] 数据迁移安全
- [ ] lint、test 和 build 通过
- [ ] 未经授权没有部署或修改线上 Secrets
