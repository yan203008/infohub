# InfoHub 页面与交互规范（简化版）

**版本**：v1.1  
**原则**：Mobile First；公开生产与私人阅读分离。

## 1. 普通用户导航

- 每日
- 感兴趣
- 笔记
- 我的

普通用户看不到管理后台、提交链接、候选内容和 API 服务信息。

## 2. 每日首页

- 默认最新一期，显示最近 7 天和“更多日期”。
- 不显示“今日采集”“昨日采集”。
- 板块：X 推特内容、热门论文、GitHub Trending、热门 YouTube、播客。
- 每个板块先展示包含内容、趋势、普通人价值、专业程度和数量。
- 点击“查看全部”展示该板块全部有效内容，不做价值筛选。
- 登录用户可以调整板块顺序或隐藏板块。

内容卡片显示标题、一句话介绍、来源、时间、阅读门槛或预计阅读时间。卡片点击进入详情，不在首页提供“不感兴趣”。“感兴趣”操作放在详情页。

## 3. 详情页

- 从首页进入时始终位于文章开头。
- 返回时恢复原列表和滚动位置。
- 顶部展示标题、来源、时间和关键词。
- 正文展示对应类型的完整加工结果和原始链接。
- 提供“感兴趣/取消感兴趣”。
- 文末提供“完成阅读”“上一篇”“下一篇”。

## 4. 感兴趣与阅读

- 标记感兴趣后进入未读。
- 打开并产生进度后进入阅读中。
- 用户主动完成后进入已读。
- 导航不显示未读数量角标。
- 从精读池继续阅读时恢复上次位置。

## 5. 划线与笔记

- 仅在用户实际选择非空文字后显示操作。
- 不自动选择整段。
- 支持高亮、批注、自由笔记、编辑和删除。
- 按文章归档，支持 Markdown 导出。
- 私人数据按当前登录用户隔离并跨端同步。

## 6. 管理后台

左侧导航：工作流、候选内容、内容管理、设置。

### 工作流

- 今日状态、最近运行和下次运行
- 采集、AI 整理、质量检查、发布四步进度
- 每个来源的发现、成功、重复和失败数量
- 失败原因、重试按钮和近期历史
- 立即运行

### 候选内容

- YouTube频道发现结果和管理员提交入口
- 单条或批量处理
- 仅处理、处理并发布、移除候选

### 内容管理

- 按日期、类型、来源和状态筛选
- 预览、编辑、重新加工、发布、撤下和重试

### 设置

- 信息源启用状态
- YouTube频道管理
- 每日运行时间和重试次数
- Get笔记、Supadata、Moonshot配置状态
- 各内容类型当前 AI 加工规则

## 7. 手机端

- 正文字号至少 17px，行高 1.6–1.8。
- 主要触控目标至少 44×44px。
- 长板块允许折叠。
- 高亮使用手机原生文字选择。
- 管理员可在手机查看失败并重试，但复杂内容编辑优先桌面。
