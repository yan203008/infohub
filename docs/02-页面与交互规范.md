# InfoHub 页面与交互规范

## 用户端

底部导航固定为：日报、精选、收藏、我的。

- 日报：首页只展示 X、热门论文、GitHub Trending 三张板块总结；点击后看全部内容。
- 精选：按展示日期倒序分组，卡片展示标题、类型、摘要和阅读时间。
- 收藏：包含“内容收藏”和“我的笔记”两个标签。
- 我的：主题、每日通知、导出与恢复私人数据。

详情页支持收藏、阅读进度恢复、同段文字划线、关联批注、完成阅读和下一篇。没有来源链接时不显示跳转入口。

主题固定为森林绿（默认）、烟灰紫、米白浅灰。

## 管理后台

后台独立使用 `admin.html`，用户端不提供入口。左侧首项为“发布文章”，默认显示文章数据表；右上角“新增文章”打开弹窗。表格依次展示展示日期、标题、Summary、主题、类型、状态、最后更新和操作。展示日期格式为 `YYYY-MM-DD`，最后更新格式为北京时间 `YYYY-MM-DD HH:mm`，两列可分别切换正序/倒序。编辑字段为：标题、卡片摘要、展示日期、类型、手动填写的 1—2 个宽泛主题、Takeaways、正文、来源链接（选填）。主题不从关键词自动生成。Takeaways 与正文都提供“简单输入”和“Markdown”两个明确模式：简单输入按照现有规则自动分段或编号；Markdown 模式直接安全渲染标题、加粗、数字列表、bullet、引用、链接、段落和分隔线，不再自动猜测或重组结构，原始 HTML 不执行。支持保存草稿、本地即时预览、确认发布、编辑、隐藏、恢复展示与删除草稿；预览不写入服务器，确认发布后才提交正式内容。

移动端允许完成完整编辑；桌面端使用编辑区与内容记录双栏。
