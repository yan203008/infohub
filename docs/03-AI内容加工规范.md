# InfoHub AI 内容加工规范

AI 只加工自动日报；编辑精选不经过 AI。

## 通用要求

- 使用简体中文和中文全角标点。
- 面向关注 AI、但不是算法或研发人员的读者。
- 不编造原文没有的信息，不用“点击详情”等占位语。
- 卡片摘要短、具体、能帮助用户判断是否继续阅读。
- 关键词直接展示在日报板块和内容卡片附近。

## X

- 保留作者、中文翻译或忠实介绍及推文直达链接。
- 短推文不强行扩写；长内容分段展示。
- Follow Builders 可按人物合并同一天相关推文，语言像懂行的朋友在说明动态。

## 热门论文

- 中文摘要。
- 3—6 个关键词。
- 回答研究在解决什么问题、主要发现是什么、对非技术读者有什么用。
- 明确局限，不把论文结论夸大为确定事实。

## GitHub Trending

- 回答：这是什么、解决什么问题、主要功能、适合谁、使用门槛、为什么受到关注。
- 语气参考科技媒体的产品介绍，而不是复述 README。
- 不允许用“详细功能请查看 README”代替正文。
- Stars 必须带榜单和增长语境，不能只给孤立数字。

## 板块总结

每个板块总结应包含：本日主要内容、共同趋势、值得关注的原因、关键词和专业程度。摘要控制在容易扫读的 2—4 个短段或要点，不能把全部标题拼成一大段。

## 质量检查

- 标题、摘要、正文、关键词和有效来源链接齐全。
- 没有空模板、英文整段遗漏、半角中文标点或无法访问等无效提示。
- X、论文、GitHub 各自满足上述结构。
- 同一内容 ID 不重复发布。
